# Pura — Singapura cat trainer

A living-room cat simulator for iPad (and desktop) that teaches an 11-year-old what it actually takes to live with a cat.

Pura is a Singapura: small, big-eared, ticked sepia coat, and busy. She has hunger, thirst, energy, a litter need, play drive, company, and comfort. If you skip play she knocks things over. If you skip the box she may go on the floor. You scoop, refill, clean, and hunt with her.

## Touch (iPad)

- **One finger on Pura** — pet. Stop if she gets overstimulated.
- **Two fingers on Pura or an object** — pick it up. Spread fingers to lift higher, release to drop.
- **One finger on a toy** — drag it across the floor (play).
- **Tap** food bag, water, litter box, or a mess to do that chore.
- **One finger on empty floor** — look around. **Pinch** empty space to zoom.
- Voice or typed commands: come, sit, play, dinner, scoop, clean up. She may ignore you.

## Stack

Next.js, React Three Fiber, Rapier physics, Zustand, Web Audio (synthesized cat / care / impact sounds), Web Speech API.

```bash
npm install
npm run dev
```
